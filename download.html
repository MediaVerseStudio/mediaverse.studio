Download MediaVerse Studio

The current release is 0.9.0 (public beta), published on 25 November 2026. MediaVerse Studio is free software under the GNU GPL, version 3 or later: no adverts, no accounts, no tracking. It is a beta, so please back up your music before using the tools that change files (each has an undo), and tell us what you find.

Windows 11

Download the Windows installer (160 MB)

  • A per-user installer: no administrator rights needed. Windows 11, 64-bit.
  • This beta installer is not code signed yet (see the code signing section below). Windows SmartScreen therefore says “Windows protected your PC”: choose More info, then Run anyway.

Android

Download the Android app (12 MB)

  • Android 11 or newer. Open the file on your phone and allow “install unknown apps” for the app you opened it from. It is signed with the project’s own key. A Google Play version comes later; if you install that, uninstall this one first.

Samsung TVs, Google TV and Linux

  • Samsung TVs: the app works on real TVs but is not a download: a Tizen app only installs on TVs named in its developer’s certificate, so it will reach you through Samsung’s store beta. You can also build and sign it for your own TV (instructions).
  • Google TV (from the Android app) and Linux (an AppImage first) are planned.

Code signing policy

This project uses the SignPath Foundation for code signing. Free code signing provided by SignPath.io, certificate by SignPath Foundation.

  • Status: the 0.9.0 beta installer above is not signed yet. Windows installers published on this page after the SignPath Foundation certificate is in use are signed, and this page will say so.
  • What is signed: only the project’s own Windows installer and program files, built from the public source in this repository. Nothing from other projects is signed with this certificate.
  • Roles: the committer, reviewer and approver is the project owner, Kris Turner (@kris-sparky). Every release is approved by hand before it is signed.
  • Privacy: the program does not send your music, your library or any usage data anywhere, and has no telemetry. It contacts an outside service only for a feature you use (for example MusicBrainz for a disc lookup, or LRCLIB for lyrics), sending only what that lookup needs. Details: privacy.
