Jellyfin integration

Better with a server, fine without one.

Jellyfin is a free media server you run at home. MediaVerse Studio works completely without it. Add it, and your music, playlists and flagged songs have a home that stays on when your computer is off.

Sign in on each device with Jellyfin's Quick Connect code. The apps talk only to a server at a home-network address.

On the computer

Two ways to use it

Share the server's folder recommended

Make the server's music share your music folder. Ripping, tag repair, covers, lyrics and organizing all work, and the server can be asked to rescan after you save.

The server alone in testing

Use the server as the whole library, with no folder. You can play and cast; tools that change files are hidden, because Jellyfin does not let other programs change them.

Finding the server

A helper looks for servers on your network, checks that a TV could sign in and that the firewall lets it through, and walks you through the setup.

Shared

What stays in step

Playlists

Playlists made on the computer or a phone appear on the server and on the TV, and changes on either side are merged. A song is only removed if both sides had it and one took it out.

Flagged songs

Flag a song on the TV or phone; it goes to a "Problem tracks" list on the server and onto the computer's review page.

Music on the phone

Choose artists, albums, playlists or everything. Edits made on the server come down; see how syncing works.

Favorites

Phones and TVs signed in to the server keep each person's favorites with it. The computer does not yet.

Profiles new

Each person gets their own favorites and playlists on the TV and phone. A profile is a Jellyfin user with no password, so anyone on your home network can pick it; remote access is switched off for it. This design will change.

Sending music test

With our MediaVerse Sync plugin, a phone can send new albums to a folder on the server to be looked over. The plugin is a test version and is not offered for download yet.

Built and tried with Jellyfin 12.4. Back up your server before trying new features on it.

Starting out

On the computer open Settings > Jellyfin. On the phone and TV, choose the Jellyfin server and approve the code shown. New to Jellyfin? Its own site explains how to install it.
