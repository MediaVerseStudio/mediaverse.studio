Linux PC

The same studio, on Linux.

The goal is a Linux program that mirrors the Windows one: organize, fix, rip, play and share, with the same screens and the same phone, TV and Jellyfin connections.

In development · there is no Linux download yet

Where it stands

Should carry over

  • The screens, which are the same web front end
  • The core that handles the library, tags, lyrics and review pages
  • Sharing with TVs and phones, and casting
  • The Android and TV apps, which need no change

Needs work

  • Converting other formats to MP3, which uses Windows' own decoders today
  • CD drive access and drive permissions
  • Installing: packages in place of the Windows setup program
  • Firewall help, file locations and secure connections

The order of work

  • Automatic builds and tests on Linux
  • The library, playback, review and settings, as an AppImage
  • Converting, then CD ripping
  • .deb, .rpm and Flatpak packages, and the Lyric AI

Features are listed for Linux only once they have been tried there. Until then, the Windows page describes the target, not what you can run on Linux.

Use Linux? We would like your help

Testers on different distributions, desktops and hardware, especially with CD drives, will be what makes this build good. Say hello on the issue board with your distribution and what you would use first.
