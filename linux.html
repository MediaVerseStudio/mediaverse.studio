Linux PC

The same studio, on Linux.

The goal is a Linux program that mirrors the Windows one: organize, fix, rip, play and share, with the same screens and the same phone, TV and Jellyfin connections.

In development · first test build made · no public download yet

Where it stands

The first test build was made on 27 November 2026: an installer (.deb) for Ubuntu 24.04 and newer, and an archive for other distributions. On a clean Ubuntu test machine it installs, starts, reads a music folder and switches sharing on. Nobody has used it on their own Linux computer yet.

In the test build, to be tried

  • The same screens as on Windows
  • Library, playback, lyrics, review and tag tools
  • Sharing with TVs and phones, casting and Jellyfin
  • The Android and TV apps need no change

Not in it yet

  • Reading and ripping CDs
  • Converting other formats to MP3, which uses Windows' own decoders today
  • The Lyric AI and photo reader downloads
  • Firewall help

The order of work

  • Try the build on real computers and fix what turns up
  • Converting, then CD ripping
  • AppImage, .rpm and Flatpak packages
  • The Lyric AI

A feature is called working only once it has been used on a real Linux computer. Until then, the Windows page describes the target, not what is proven on Linux.

Use Linux? We would like your help

Testers on different distributions, desktops and hardware, especially with CD drives, will be what makes this build good. Say hello on the issue board with your distribution and what you would use first, and ask to try the test build.
